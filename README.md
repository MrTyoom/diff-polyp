# Синтез полипов по маске для аугментации Kvasir-SEG

Дипломная работа, 4 курс. Срок: ноябрь 2026 – май 2027.

**Цель:** оценить пользу синтетических эндоскопических снимков для сегментации полипов и роль фильтрации синтетики.

**Идея:** ControlNet генерирует снимки с полипом заданной формы. Детектор сгенерированных изображений (R24) и проверка согласованности с маской отбирают синтетику. Сегментатор обучается на смеси реальных и синтетических снимков, а прирост Dice измеряется против честных бейзлайнов.

```
маска ──► ControlNet (SD 1.5) ──► синтетика ──► фильтр ──► real + synth ──► сегментатор ──► Dice / IoU / HD95
                                                 ├─ детектор R24 («похоже на настоящее?»)
                                                 └─ согласованность с маской («полип там, где маска?»)
```

---

## Исследовательские вопросы

| # | Вопрос |
|---|---|
| RQ1 | Даёт ли синтетика прирост над сильной классической аугментацией, на Kvasir-SEG и на внешних датасетах (CVC-ColonDB, ETIS, PolypGen)? |
| RQ2 | Помогает ли фильтрация в сравнении со случайной подвыборкой того же размера? |
| RQ3 | Какой критерий отбора полезнее: реалистичность (детектор R24) или согласованность с маской? Связана ли оценка детектора с пользой примера для обучения? |
| RQ4 | Даёт ли прирост новизна формы маски (маски из train, деформированные, сгенерированные)? |
| RQ5 | Сколько синтетических снимков заменяют один реальный? |

### Ключевые выводы обзора

- **Прирост на тесте Kvasir-SEG обычно не больше одного пункта Dice**, иногда отрицательный. Заметный прирост бывает у слабых сегментаторов и на других датасетах.
- **Фильтрация в полипах была только смысловая.** ControlPolypNet оставляет снимки, где YOLOv8 видит полип с confidence 0.7–0.8. DiffAug оставляет снимки, где IoU между заданной и предсказанной маской больше 0.7. Детектор сгенерированных изображений как фильтр не применялся. Сравнения со случайной подвыборкой того же размера в прочитанных работах нет.
- **Новые маски делали** Macháček, ControlPolypNet, DGS и Polyp-LDM, но связь новизны формы с приростом никто не измерял.
- **Главный источник шума — расхождение полипа с маской** (Polyp-LDM), то есть неверная разметка синтетики.
- **Протоколы в области ненадёжны.** Встречается не меньше пяти несовместимых сплитов Kvasir-SEG/ClinicDB, тестов значимости почти нигде нет.
- **Риск меморизации:** латентные диффузионки запоминают обучающие снимки, а на 1000 изображениях риск особенно высок.

### В планах

**Этап 1. Протокол и бейзлайны**
- [ ] Выбрать и зафиксировать сплит Kvasir-SEG (train / val / test) и больше его не менять.
- [ ] Подготовить внешние тесты: CVC-ColonDB, ETIS, PolypGen. Они используются только для оценки.
- [ ] Положить данные под DVC, логировать в TensorBoard.
- [ ] Обучить сегментаторы: U-Net (ResNet34) и один сильный (Polyp-PVT или SegFormer).
- [ ] Бейзлайны: без аугментации и с сильной классической аугментацией (flip, rotate, color jitter, elastic).
- [ ] Метрики: mean Dice, IoU, HD95, recall по полипам, отдельно подгруппа малых полипов.
- [ ] Запускать каждую конфигурацию на 3–5 сидах, считать парный тест и bootstrap-интервалы.

**Этап 2. Генерация**
- [ ] Дообучить ControlNet (SD 1.5) на парах маска–снимок из train.
- [ ] Подготовить три источника масок: маски из train, деформированные (elastic, морфология), сгенерированные.
- [ ] Ввести метрику новизны формы, например расстояние до ближайшей маски из train.
- [ ] Сгенерировать пул синтетики с запасом под фильтрацию (в несколько раз больше train).
- [ ] Проверить меморизацию: поиск ближайших соседей синтетики в train по признакам DINO или SSCD.

**Этап 3. Фильтры**
- [ ] Обучить детектор по R24 на парах реальный–синтетический снимок.
- [ ] Контроль: реальные снимки, пропущенные через encode–decode VAE. Если детектор считает их подделками, он ловит отпечаток декодера, а не смысловые дефекты.
- [ ] Фильтр согласованности: Dice между заданной маской и предсказанием сегментатора, обученного на реальных данных.
- [ ] Сравнить стратегии отбора: самые «реальные» по детектору и средние по оценке (самые реальные могут оказаться копиями train).

## Матрица экспериментов

| ID | Обучающая выборка | Что проверяет |
|---|---|---|
| E0 | Только реальные, без аугментации | нижняя граница |
| E1 | Реальные с классической аугментацией | **основной бейзлайн** |
| E2 | E1 + вся синтетика без фильтра | RQ1 |
| E3 | E1 + случайная подвыборка синтетики размера K | контроль для RQ2 |
| E4 | E1 + top-K по детектору R24 | RQ2, RQ3 |
| E5 | E1 + top-K по согласованности с маской | RQ2, RQ3 |
| E6 | E1 + оба фильтра | RQ3 |
| E7 | E1 + N реальных снимков из другого датасета | RQ5 |
| E8 | E2/E6 с разными источниками масок | RQ4 |
| E9 *(опционально)* | E2/E6 с пиксельным генератором | влияние латента на синтетику и детектор |

Для E2–E6 строятся кривые по доле синтетики (×0.5, ×1, ×2, ×4 от train): в литературе качество часто падает при большом объёме синтетики.
